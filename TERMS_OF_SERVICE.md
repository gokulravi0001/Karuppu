## 3. Description of Services
Karuppu provides automated Discord security, moderation, anti-raid containment, and server activity audit logging services. Key capabilities include:
- **Raid Containment & Surge Defense**: Detection of rapid coordinated join floods, account age auditing, and bulk containment tools.
- **Heuristic Threat Filtering**: Sliding-window inspection of spam bursts, repetitive copypasta, credential harvesting links, known phishing domains, and malicious executable attachments.
- **Automated Moderation & Progressive Trust**: Configurable automated warnings, message purges, timeouts, kicks, and bans.
- **Comprehensive Audit & Activity Logging**: Structured log routing for message events (edits/deletions), member events (role/nickname updates), channel permission changes, and voice channel state transitions (moves, server deafens, video/streaming toggles).
- **Web Dashboard**: An interface for authorized guild administrators to inspect incident logs, configure thresholds, and manage server security rules.
