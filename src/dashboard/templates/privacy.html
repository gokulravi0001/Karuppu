Privacy Policy

1. Introduction & Commitment to Privacy

This Privacy Policy explains how Karuppu Security Bot ("Karuppu", "we", "us", or "our", Application ID: 1560663818353381467) collects, processes, protects, and retains data when you use the bot within your Discord servers or access its web dashboard.

Karuppu was engineered around a foundational Privacy-by-Design architecture: we collect only the minimal data necessary to deliver server protection, automated moderation, raid containment, and activity logging. We do not surveil members or monetize personal data.

2. Information We Collect & How It Is Used

To perform automated server security and activity auditing, Karuppu processes the following data:

Discord Platform Identifiers

User IDs, Server (Guild) IDs, Channel IDs, and Role IDs. These public Discord identifiers are utilized strictly to identify server contexts, route activity logs to configured channels, and maintain role hierarchy configurations.

Account Timestamps & Join History

Account creation timestamps and server join timestamps. Used solely to calculate account age for raid wave detection, spam-bot filtering, and progressive trust role progression.

Audit & Voice Channel State Events

Voice state transitions (e.g. member joins, moves, disconnects, video/streaming status, mute/deafen flags) and administrative audit events (e.g. channel permission overrides, nickname updates, role creations). These events are formatted in real time and delivered directly to designated private server log channels chosen by server administrators.

Ephemeral In-Memory Scanning (Zero Persistent Message Storage)

We do not store chat logs or messages in persistent databases. Real-time message content is evaluated in temporary, volatile memory (RAM) through a sliding window buffer with a strict 60-second Time-To-Live (TTL) to detect spam bursts, duplicate copypasta, and phishing domains. Once evaluated, harmless messages are completely discarded from memory.

Cryptographic Incident Evidence

When an active security violation occurs (e.g., confirmed phishing link or malicious file upload), only a one-way cryptographic SHA-256 hash of the offending payload along with a brief, truncated snippet (maximum 60 characters) is retained in server incident records for administrative verification.

3. Data Retention & Automated Pruning

We maintain a strict data lifecycle policy:

  • Operational In-Memory State: Cleared automatically every 60 seconds.
  • Security Incident & Audit Records: Stored in an encrypted local database and subject to an automated 30-day retention pruning cycle. A scheduled daily maintenance worker permanently wipes all incident logs older than 30 days.
  • Server Configurations: Server settings (such as designated log channels and sensitivity thresholds) are retained only while the bot remains a member of your server.

4. Third-Party Sharing & Commercialization Policy

🔒 Zero Data Selling Guarantee

We never sell, monetize, rent, or lease your data to any third party. We do not share user identities, server statistics, or incident logs with advertising platforms, data brokers, telemetry trackers, or external analytics firms.

5. Data Security & Infrastructure

Karuppu runs on secured containerized infrastructure with strict least-privilege access controls. Communication between the bot, Discord API, and web dashboard is encrypted in transit using industry-standard TLS/HTTPS. Web dashboard sessions utilize cryptographically signed tokens.

6. User Rights & Data Deletion (GDPR & CCPA Compliance)

We fully respect your rights regarding data access and deletion:

  • Server Removal: Removing or kicking Karuppu from your Discord server halts all data collection immediately.
  • Complete Data Deletion: Server owners or individual users may request complete deletion of all stored server settings, incidents, and metadata by submitting a request to our GitHub issue tracker or contacting the project developer. Requests are processed within 48 hours.

7. Children's Privacy

Karuppu is not intended for use by anyone under the age of 13 (or the minimum legal age for Discord usage in your jurisdiction). We do not knowingly collect personal information from children under 13.
