Privacy Policy

Effective Date: October 20, 2026 • Last Updated: October 20, 2026

1. Overview & Privacy-by-Design

Antigravity Security is built with strict privacy-by-design standards. We believe that security should never require surveillance. We collect and retain only the minimal operational data required to detect raids, filter scam links, and provide server activity logs.

2. Information We Collect

When operating in a Discord server, the application processes the following types of data:

  • Discord Identifiers: Discord User IDs, Server (Guild) IDs, and Channel IDs.
  • Account Metadata: Account creation dates and server join timestamps (utilized strictly for raid surge detection and account age audits).
  • Security Incident Hashes: When a suspicious phishing link or spam burst is flagged, the message content is cryptographically hashed using SHA-256 and stored alongside a short redacted 60-character snippet for moderator review.
  • Activity Log Feeds: Message edits (before/after), deletions, and voice channel state transitions routed to your server's designated private log channels.

3. Ephemeral In-Memory Processing (No Long-Term Message Storage)

We do not permanently store raw message contents. All standard message scanning (rate limiting, copypasta duplicate checking, and phishing checks) occurs in fast, temporary in-memory sliding buffers with a strict 60-second Time-To-Live (TTL). Once a message passes heuristics, it is completely wiped from runtime memory.

4. Data Retention & Automated Deletion

Structured security incident records stored in the server's local database are automatically pruned by a daily background maintenance task. Records older than the configured retention window (default: 30 days) are permanently purged from the database.

5. Third-Party Sharing & Commercialization

We never sell, lease, or monetize your data. We do not share Discord user information, server settings, or audit logs with advertising networks, third-party analytics providers, or external data brokers.

6. User Rights & Data Removal Requests

Server administrators have full control over their server's database records. Removing the bot from a server and deleting the container volume permanently deletes all associated server records. If an individual user wishes to request deletion of specific incident logs, they may contact the server administrator or submit a request via our GitHub repository.

7. Contact & Privacy Inquiries

For questions regarding this Privacy Policy or our security handling practices, please contact us on GitHub: https://github.com/gokulravi0001/Karuppu
