3. Description of Services

Karuppu is an advanced automated security, moderation, and activity audit system engineered to protect Discord servers. Key features provided include:

  • Raid Containment & Surge Defense: Real-time detection of coordinated join floods, automated verification gating, and mass account quarantines.
  • Heuristic Threat Filtering: In-memory sliding-window inspection of spam bursts, repetitive copypasta, credential harvesters, known phishing domains, and malicious executable attachments.
  • Automated Moderation & Progressive Trust: Configurable penalties including warning embeds, message deletions, temporary mutes/timeouts, kicks, and bans.
  • Comprehensive Audit & Activity Logging: Dedicated channel logs for message edits/deletions, member nickname/role changes, channel permission overwrites, and voice channel state transitions (moves, server deafens, video/streaming toggles).
  • Web Dashboard & Administration: A secure interface for server administrators to inspect security incidents, configure thresholds, and manage server rules.
